# Project Nova

Kiwi Hacks Hackathon project by group James Street. This follows the prompt of "my place in space".

We are building a ESP32 quadruped robot called Rover Nova that acts how it would move under the gravity and conditions of different planets. It's controlled by a control panel via a phone web page.

It features 4 legs, moving pose animations, and an OLED screen that displays faces and planets.
